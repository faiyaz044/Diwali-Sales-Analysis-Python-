# Diwali Sales Analysis

## 📌 Project Overview

Diwali Sales Analysis is a Python-based data analysis project that analyzes Diwali sales data to understand customer purchasing behavior, sales trends, and business performance.

The main goal of this project is to find useful insights from the sales data that can help businesses understand their customers and improve their sales strategies.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed

- Analyzed overall sales data
- Studied customer purchasing behavior
- Analyzed sales based on gender
- Analyzed sales based on age group
- Identified top-performing states
- Analyzed occupation-wise purchasing behavior
- Analyzed product categories
- Identified the most popular products
- Created visualizations to understand sales trends

## 🔍 Key Insights

The analysis helps identify:

- Which age group contributes the most to sales
- Which gender has higher purchasing activity
- Which states generate higher sales
- Which occupations have higher purchasing power
- Which product categories are most popular
- Which products have the highest demand
